A School Day

A 45-second video of a boy's school day, 7:00 AM to 8:30 PM. Every room, prop, motion and sound effect is code. The boy is 9 stickers.

Read the development journey → Source on GitHub Reference: Eric's Claude Code animation video

How it was made

  • Claude Code wrote a web page: SVG rooms, the 9 sticker cut-outs, and one GSAP timeline of 45 seconds.
  • HyperFrames opened the page in headless Chrome and captured 1350 frames (30 per second); FFmpeg encoded them.
  • Narrator and music: ElevenLabs. Sound effects: a Python script with the standard library only.
  • 1920×1080, 30 fps, 45.0 s, −13.8 LUFS. Render time: 1 min 7 s.
