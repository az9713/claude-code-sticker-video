0. Read this first: how code makes a video

Most people think an AI video is "generated" as pixels. This video was not. No model drew a frame. Every frame is a web page that a browser draws, and a program takes a photo of it.

Here is the full idea in five sentences:

  1. A web page can draw shapes (SVG), show pictures (<img>), and show text.
  2. A JavaScript animation library (GSAP) can move those things according to a timeline: "at 12.5 s, the lava jumps up 200 px".
  3. A timeline can be paused and moved to any time, the same way you can drag a video's progress bar.
  4. A render tool (HyperFrames) opens the page in a hidden Chrome, moves the timeline to 0.000 s, takes a picture, moves to 0.033 s, takes a picture, and so on: 30 pictures for each second, 1350 pictures for 45 s.
  5. FFmpeg joins the 1350 pictures into an MP4 and mixes in the sound files that the page lists with their start times.
stickers.png ──(Python cuts)──► 9 PNG files ─┐
                                              │
lib/library.js (sets, props, boy, clock) ─────┼──► index.html (one paused GSAP timeline, 45 s)
                                              │            │
ElevenLabs voice + music, Python SFX ─────────┘            │ <audio data-start=...> tags
                                                           ▼
                         npx hyperframes render: Chrome seeks t = 0, 1/30, 2/30 … 44.967 s
                                                           ▼
                         1350 frames + audio mix ──FFmpeg──► school-day-45s.mp4
                                                           ▼
                         ffmpeg gain + limiter ──► school-day-45s-14lufs.mp4 (the deliverable)

The rule that makes this possible: the page must draw the same picture every time it is asked for the same time. That is why the code never uses Math.random() or the clock. A "random" lava splash uses a fixed number generator with a fixed seed, so frame 377 is identical on every render.

The video is code in these places: the rooms, the props, the motion, the camera push-in, the clock badge, the colour wipes, the sound effects. It is not code in these places: the boy (9 stickers the user supplied), the narrator's voice and the music (both from ElevenLabs).

3.2 Make the project (tool: HyperFrames CLI)

This wrote index.html (an empty composition), package.json (scripts pinned to hyperframes@0.8.143), hyperframes.json, meta.json, CLAUDE.md and AGENTS.md (rules for the AI). A HyperFrames project is just a folder with a web page in it. There is no special file format.

3.3 Cut the 9 stickers (tools: Python, Pillow, NumPy, SciPy)

A PNG with transparency has a 4th channel, alpha: 0 means "nothing here", 255 means "solid". Each sticker is an island of solid pixels in a sea of alpha 0. SciPy's ndimage.label finds islands (it is the same idea as a "paint bucket" fill that counts the separate areas).

  1. Mark every pixel with alpha > 16 as solid.
  2. ndimage.label found 49 islands.
  3. Put each island in the grid cell (3×3, 418 px each) that holds its centre.
  4. Drop islands smaller than 200 px. 40 islands were dust (stray specks). In each cell exactly 1 island was bigger than 200 px — the whole sticker, because the white die-cut border joins the "zZ", "!!", hearts and stars to the boy.
  5. Crop each sticker to its own box and save it: assets/stickers/{peace,guitar,pizza,sleepy,laugh,surprised,grumpy,thumbs,hearts}.png. The sizes were 338–386 px wide and 340–426 px high.
  6. Paste all 9 on a blue sheet and look at it (scratchpad/cut-check.png).

Near-miss. The 200 px filter could have dropped a real part of a sticker (a separate "Z", a separate heart). The blue check sheet is what proved it did not: every "zZ", "!!", star and heart was still there. Rule learned: a filter that throws data away needs a picture that shows what is left.

  1. Upscale 2× with Lanczos (Pillow Image.LANCZOS). On screen the boy is 600–720 px high, so the small files would be stretched 1.6–2× by the browser. Pillow's Lanczos filter makes a cleaner bigger image than the browser's live scaling. New sizes: e.g. grumpy 740×680, guitar 720×852. The original sheet is kept, so this is reversible.

3.4 Load the HyperFrames rules (tool: Skill)

  • hyperframes-core — the contract a page must follow to be rendered. The rules that mattered here: one paused timeline registered as window.__timelines["main"]; every timed element has data-start and data-duration; every <audio> has an id (an audio tag with no id is silently left out of the mix); never animate a .clip element's visibility (the renderer owns that); no Math.random, no clock.
  • hyperframes-animation — GSAP rules: only move things with x, y, scale, rotation, opacity; never set a CSS transform on something GSAP also moves.

3.8 Make the music (tool: ElevenLabs creative_generate_in_flow, node_type: music, model_id: eleven_music_v2)

Prompt: "45 seconds, instrumental only, no vocals. Playful, warm children's cartoon underscore: ukulele, glockenspiel, light pizzicato strings, soft hand claps, gentle 105 BPM. Bright and bouncy for the first 35 seconds, then it slows and softens into a quiet music-box lullaby for the last 10 seconds …"

Result: 45.0 s (ffprobe: 45.024 s), 1800 credits (US$0.30).

Two checks, because the status said Instrumental: False and Lyrics type: auto although the prompt said "no vocals": - Vocals? faster_whisper with vad_filter=True (voice activity detection) found no speech segments. - Loudness over time (ffmpeg … -af volumedetect on 3-second windows): −20.0 dB at 0 s, −19.8 at 10 s, −20.2 at 20 s, −17.9 at 30 s, −18.5 at 36 s, −39.8 at 40 s, −66.7 at 43 s. The track does not play a lullaby; it fades out by about 40 s. I accepted that and added a coded music-box sound for bedtime (step 3.10).

3.9 Find the word times and cut the voice into 9 lines (tools: faster-whisper, ffmpeg silencedetect, ffmpeg)

  1. Word times. WhisperModel('base.en', device='cpu', compute_type='int8') with word_timestamps=True gives a start and end time for every word. Saved in words.txt. Example: "volcano" 8.98–9.38 s, "erupts" 9.38–10.04 s.
  2. Silences. ffmpeg -af silencedetect=noise=-38dB:d=0.12 lists every pause longer than 0.12 s quieter than −38 dB.
  3. Cut points = the middle of the pause between two lines: 0, 3.75, 7.0, 10.88, 14.29, 17.02, 20.46, 23.26, 25.94, 28.96 s.
  4. Cut each line with ffmpeg (-ss start, -t length) and a 0.02 s fade in and 0.04 s fade out, so a cut never clicks. Files: assets/vo-1.mp3 … vo-9.mp3, lengths 3.79, 3.29, 3.92, 3.45, 2.77, 3.47, 2.85 (2.80 for the player), 2.72, 3.06 s.

3.10 Make the sound effects with code (tool: make_sfx.py, Python standard library only)

A WAV file is a long list of numbers between −1 and 1, 44,100 per second. A sound effect is a formula that makes that list. make_sfx.py writes 9 files; it uses a seeded random generator (random.Random(7)), so the files are the same on every run.

File How the formula makes it
sfx-alarm.wav A 2.2 kHz square wave (the sign of a sine), on 0.09 s, off 0.05 s: three double beeps
sfx-whoosh.wav Random noise through a filter whose brightness rises then falls, 0.45 s
sfx-bell.wav Three bell tones (1250, 2710, 4100 Hz) struck again 12 times a second, 1.3 s
sfx-fizz.wav A low thump that slides from 90 Hz down, plus hissing noise that fades — the volcano
sfx-sparkle.wav Four glockenspiel notes C6–E6–G6–C7 that each ring and die away
sfx-strum.wav Karplus-Strong plucked strings: a short burst of noise is fed round a loop and averaged each pass, which sounds like a string. Six strings of an E major chord, 25 ms apart
sfx-pop.wav A 0.12 s tone that drops in pitch
sfx-twinkle.wav A music-box phrase E5 D5 C5 D5 E5 E5 E5, 0.42 s apart — replaces the missing lullaby
sfx-boing.wav A wobbling tone that dies away, for the laugh

3.11 Write the style bible (file: style-bible.md)

This is Eric's step 2: one page that every scene must obey. Key rules: - The boy is only a sticker PNG. Never redraw, recolor or crop him, never remove the white border. - Bust stickers hide their flat bottom behind a prop or below the frame. - One sticker on screen at a time, 600–720 px high; motion pivots at the bottom centre. - Palette: ink #2b2420 for every outline and text; paper #fff8ec; sweater grey #8c8783 and skin #fdbf81 sampled from the stickers with Pillow; sky per time of day — dawn #ffd6a8, day #a8dcf2, dusk #f7a983, night #22305c. - 6 px outlines, round joins, flat fills, no gradients, no blur, no shadows. - Cuts hide behind a full-frame colour wipe (0.25 s in, 0.3 s out) with a whoosh.

3.12 Build the library (file: lib/library.js, 421 lines)

This is Eric's step 3 and the centre of the method: build each part once, give it a name, then direct it. The scene file never draws a shape itself. It only calls names.

Layers. stage(section) gives each scene 4 stacked layers inside a .cam box (the camera):

.cam (scales 1.00 → 1.06 for a slow push-in)
 ├─ back  <svg>  the room: wall, window, furniture behind the boy
 ├─ slot  <div>  the boy (an <img>)
 ├─ front <svg>  things in front of him: blanket, desk, table
 └─ fx    <svg>  stars, hearts, notes, lava, word bubbles

Because the blanket is in front and the boy is in slot, the boy is really "in bed". That is how the flat bottom of a bust sticker is hidden.

Sets (each draws back and front): bedroom (sky: "dawn" with a rising sun and the alarm clock, or sky: "night" with moon, twinkling stars and a lamp), street (houses, school, road, school bus), classroom (board: "SCIENCE" with a lab desk and volcano, or board: "SPELLING TEST" without a desk), playground, cafeteria (banner "PIZZA DAY!"), musicRoom (amp, posters), dining (lamp, cake, striped tablecloth). Every shape is SVG written as text: a rectangle is <rect x=… y=… width=… height=…>, a star is a 10-point path computed with sine and cosine, a heart is two curves.

Named props. A prop that moves is wrapped twice: an outer <g transform="translate(x y)"> puts it in place, an inner <g data-name="bus"> is what GSAP moves. A set returns all named parts, so the scene can write r.bus, r.alarm, r.lavaDrip. (Two layers are needed because GSAP rewrites the transform of what it moves; if the position were on the same element, moving x could lose y.)

The boy. boy(stage, "pizza", { x: 800, bottom: 1000, h: 660 }) places the sticker by its bottom-centre and returns 5 named motions:

Motion What GSAP does
pop(tl, at) Sticker slaps on: scale 0.2 → 1, rotation −10° → 0, opacity 0 → 1, back.out(2.2) overshoot, 0.45 s
hop(tl, at, height, times) Moves up and back down (yoyo)
squash(tl, at) Short and wide for 0.12 s, then back
wiggle(tl, at, deg, times) Fast left-right rotation
sway(tl, at, dur, deg) Slow rocking, for the guitar and for sleep

Floaters. fx(stage, "heart", x, y, count, seed) makes count copies at one point. The scene then moves each copy up and out. Positions come from a seeded LCG generator (s = s * 1664525 + 1013904223), never from Math.random(), so every render is the same.

Clock badge. UI.clockBadge(parent, items) draws a clock face and 9 stacked labels ("7:00 AM / Wake up" …). The hands only turn forward, so their angles are counted from the start, not taken modulo 360: hour hand = minutes since midnight × 0.5°; minute hand = (minutes − 420) × 6°. From 7:00 to 8:30 PM the minute hand turns 810 × 6 = 4860°, 13.5 full turns, spread over 8 scene changes of 0.6 s each.

3.13 Direct the scene (file: index.html, 231 lines)

Clips. Nine <section class="clip"> elements, data-start 0, 4.8, 9.6 … 38.4, data-duration 4.8 (the last one 6.6). The renderer shows a clip only inside its time window, so a scene change needs no code. One more clip, #overlay, runs 0–45 s and holds the clock badge, the 8 colour wipes and the final fade.

Sound. 32 <audio> tags (1 music, 9 narrator lines, 22 sound effects), each with id, src, data-start, data-duration, data-volume. Narrator line i starts 0.5 s after its scene (line 1 at 0.6 s). The music bed is turned to volume 0.22 by a timeline tween.

Timeline. One gsap.timeline({ paused: true }) holds every move, at absolute times. The cues come from words.txt: global time = scene start + 0.5 + the word's time inside its cut line. Examples:

Time (s) What happens Why that time

3.17 Loudness (tool: ffmpeg)

Streaming platforms play audio at about −14 LUFS (LUFS = loudness as people hear it, averaged). The raw render measured −19.3 LUFS, true peak −5.91 dBTP. True peak must stay below about −1 dBTP, or the sound distorts on some players. It took 4 tries (section 5, item 9). The final command:

ffmpeg -i school-day-45s.mp4 -af "aresample=192000,volume=6.6dB,alimiter=limit=0.7:level=disabled:attack=1:release=50,aresample=48000" \
  -c:v copy -c:a aac -b:a 192k -t 45 school-day-45s-14lufs.mp4

It makes the sound 6.6 dB louder, catches peaks with a limiter at 0.7 (−3.1 dBFS) at 4× sample rate, copies the video untouched, and keeps exactly 45 s. Result (ebur128): −13.8 LUFS, LRA 9.7 LU, true peak −2.2 dBTP.

4. Design decisions — what was chosen and what lost

Decision Chosen Rejected, and why
The boy Sticker cut-outs SVG rig redrawn in sticker style: lip sync possible, but he would only look similar. The user chose identical.
Lip sync None Rhubarb gives mouth shapes, but a sticker has no separate mouth to swap.
Voice production One take, cut into 9 lines 9 separate takes: 9 jobs to wait for, and the voice can drift between takes. Regenerate one slower take: costs credits again and still gives no control of where each line falls.
Scene timing Fixed grid: 4.8 s per scene, line starts 0.5 s in Timing driven by the full take: with a 28.96 s take, 45 s of video would leave 16 s of silence. Cutting lines and putting them on a grid fills 45 s evenly. (This overrode the advisor's "scene starts on the first word"; the cut lines keep the spirit — every cue still sits on a measured word time.)
Structure 9 timed <section> clips in one file One 45 s clip (needs code to show/hide scenes); 9 sub-composition files (more files, the lint warns it would be "easier to read", but more to wire).
Transitions Colour wipe panels Shader transitions: they switch the render to a transparent background path. Crossfades: two busy rooms mixed look muddy.
Upscaling Pillow Lanczos 2× once Browser scaling at render: softer edges.
Bedtime music Coded music box Regenerate music: 1800 more credits for 5 seconds.
Captions None Not asked. The clock badge names each scene.
Boy's name None Not given; I did not invent one.
Other people Shown by props only (lunch tray, family table, plates) Drawing a mother or a friend would add characters that are not stickers and break the style.

5. What went wrong, and the fixes

  1. The first request was interrupted by the user and re-sent with "use the same workflow as last one". I had only read files at that point; nothing was lost.
  2. The voice was 28.96 s, not ~41 s. Fix: cut it into 9 lines and place them on a fixed grid (section 4).
  3. The music ignored half of its prompt. It has no lullaby ending and fades out by 40 s (−39.8 dB at 40 s, −66.7 dB at 43 s), and the run settings said Instrumental: False. Fix: Whisper VAD check (no vocals found); coded sfx-twinkle.wav for bedtime. Lesson: a generator's prompt is a request, not a spec — measure the output.
  4. check error — layout: content_overlap … "Z" — Two text blocks overlap and may render unreadable. at t = 40.75–42.25 s. The three floating "Z" letters used a spread of 120 px, so their x offsets were −60, −43, −26 px. Fix: spread 300 px (offsets −150, −13, +124 px).
  5. check error — contrast: … text 1.22:1 (need 3:1, t=42.5s). The last "Z" was still fading (almost transparent) when the audit sampled it. Fix: shorter float (gap: 0.4, dur: 1.6), so the last Z is gone by 42.4 s.
  6. check warning: clip_media_fit: Audio "vo-7" is 2.80s but its slot (data-duration) is 2.85s. ffprobe said 2.847 s, the player measured 2.80 s. Fix: data-duration="2.8". 9. Glossary

Term Meaning here
Frame One still picture. This video has 30 per second, 1350 in total.
Composition The web page that HyperFrames renders (index.html).
Clip An element with data-start and data-duration; it is visible only in that window.
Timeline GSAP's list of "at time T, move X to Y". Paused, so the renderer can jump to any time.
Seek Jump the timeline to an exact time. The renderer seeks once per frame.
Deterministic The same time always gives the same picture. Required, because frames are rendered in parallel and out of order.
SVG Shapes described as text (<rect>, <circle>, <path>), drawn by the browser at any size.
Alpha channel The transparency value of each pixel. Used to find the stickers.
Lanczos A resize filter that keeps edges sharp when an image is made bigger.
Ease The speed curve of a move (back.out overshoots, bounce.out bounces).
LUFS Loudness as people hear it. −14 LUFS is the common streaming level.
dBTP / true peak The highest point of the waveform, including peaks between samples. Keep below −1.
Karplus-Strong A short formula that makes a plucked-string sound from a burst of noise.
MCP connector A plug-in that lets Claude call an outside service (here ElevenLabs) as a tool.
